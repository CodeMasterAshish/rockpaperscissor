StonePaperScissor
🪨📄✂️ Stone Paper Scissors Game
A simple and fun Stone–Paper–Scissors game built using HTML, CSS, and JavaScript.
This project helped me understand basic JavaScript logic, functions, conditionals, and DOM concepts.

🚀 Features
Play Stone / Paper / Scissors against the computer
Computer choice is generated randomly
Score is tracked for both Human and Computer
Clean and responsive UI
Beginner-friendly code structure
🛠️ Tech Stack
HTML – Structure of the game
CSS – Styling and layout
JavaScript – Game logic
🎮 How the Game Works
User selects Rock, Paper, or Scissor
Computer randomly selects one option
Winner is decided using standard rules:
Rock beats Scissor
Paper beats Rock
Scissor beats Paper
Scores are updated after each round
🧪 Play Using Inspect / Console Mode
This game can also be played directly in the browser console.

Steps:
Open the project in your browser
Right-click → Inspect → go to Console
Refresh the page
Enter your choice when prompted (rock, paper, or scissor)
View results and scores in the console
⚠️ Make sure to open the Console tab before playing in inspect mode.
